# FlowCanvas

FlowCanvas 是一个本地优先、数据驱动、高度可自定义的通用节点流程系统。

底层模型不绑定学习计划或其他特定业务（学习计划仅作示例数据），可用于流程展示、项目路径、操作指引、审批、巡检和决策路径等场景。

## 核心方向

- 元字段与节点模型分离，驱动方案、驱动绑定与流程拓扑分离。
- 配置域与执行域严格分离：配置域一切活引用，发布是唯一快照门。
- 发布不可变流程快照（FlowVersion），已有执行实例不受后续配置修改影响。
- 状态引擎采用轻量事件溯源：只有事实进日志，生命周期与关注状态永远由纯函数重算得出。
- 本地优先（IndexedDB + `.flowpack` 导入导出），云同步走个人云盘应用目录，永不静默覆盖。
