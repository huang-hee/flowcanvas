# FlowCanvas

FlowCanvas 是一个本地优先、数据驱动、模板可切换的通用节点流程生成项目。

项目底层模型不绑定学习计划或其他特定业务，可用于流程展示、项目路径、操作指引、知识地图、依赖图和决策路径等场景。

## 当前阶段

当前仓库保存产品方案与设计契约，后续将在此基础上实现前端配置中心、流程画布和独立执行实例。

## 核心方向

- 元数据字段与节点数据结构分离。
- 驱动方案、驱动绑定与流程拓扑分离。
- 配置域与执行域严格分离。
- 发布不可变流程快照，保证已有实例不受后续配置修改影响。
- 优先支持本地数据与可移植的 JSON/YAML 配置。
