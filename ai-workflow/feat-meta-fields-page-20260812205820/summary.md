## 1. 交付了什么

FlowCanvas **代码从零到一**。本次不是「做一个页面」，而是纵切了一条从协议到 UI 的最小可运行链路。

| 层 | 交付 |
|---|---|
| 工程 | pnpm monorepo、TS strict、ESLint(typescript-eslint) + Prettier、vitest、GitHub Actions CI |
| `packages/core` | `schema/`：MetaField 全套 zod 协议（11 种数据类型 / 8 型校验规则 / 精度与单位 / 内置时间单位组）+ 精度归一 + 空值归一；`ports/`：`StorageAdapter` 接口 |
| `apps/web` | IndexedDB 适配器与 MetaField 仓储、控制台外壳（侧栏 + PageHeader）、元字段页（列表 / 抽屉 / 三浮层）、antd 主题接线 |
| 质量 | 75 个测试（协议 44 + 组件 31），lint / typecheck / build / test 四绿 |

**刻意没做**：`core/engine`、`core/publish`、`core/diagnostics`——它们与本页无关（`06 §2` 的依赖顺序把它们排在前面，但那是全局顺序，不是本页的前置）。

## 4. 三处无设计稿依据的推导（⚠️ 补稿后需返工）

1. **enum 选项行 / list 子项类型控件**（`spec-ui §4`）——Figma 的抽屉表单只画了 number 类型的态。形制照 RuleRow 推导。**行为不受影响，样式可能返工。**
2. **六项菜单图标**——`08 §2.3` 只要求「各配一枚 `@ant-design/icons` 图标」，未指定具体图标。
3. **其余五页的路由路径**——只有 `/meta-fields` 来自 `05 §2`，其余五条为新拟，各页开工时须以 `05 §2` 复核。
