## 1. 背景

FlowCanvas 方案文档已封板，**代码侧一行未写**。元字段是主干链路 `元字段 → 节点模型 → 驱动绑定 → 节点编排 → 发布 → 执行` 的起点，也是七个页面中**唯一已有定稿 UI 设计**的一页（`09 §1` 总览表）。

`06 §2` 把它排在阶段一步骤 6 第 2 项，前面压着步骤 1–5。停顿 1 确认：**不按 06 的全序推进，走纵切**——只起这一页真正需要的前置，`core/engine`、`core/publish`、`core/diagnostics` 与本页无关，本次不做。

### 2.2 不做什么

- **`core/engine` / `core/publish` / `core/diagnostics`**——事件模型、recompute、驱动器计算、发布固化、六层校验，与本页无关，留给里程碑一后续。
- **其余六个页面**——仪表盘、节点模型、驱动方案、流程画布、实例列表、执行实例。它们的 UI 设计尚未定稿（`09 §1`），`06 §2` 明确「每页开工前须先有 09 的定稿设计」。
- **object / list(object) 的内部结构编辑**——按 `00 决策 29`，组合下沉到节点模型层的子组装，元字段保持原子（`09 §2.4` 已明确"不做"）。

- **云同步、`.flowpack` 导出/导入**——阶段二与阶段一步骤 8 的内容。

## 3. 验收条件

**逐条可测**（事项粒度判据：能被已确认的测试用例覆盖）。编号供 `spec-test.md` 对齐。

### A. 数据与协议

| # | 条件 |
|---|---|
| A1 | 可创建元字段，`dataType` 覆盖全部 11 种（text / multiline / number / boolean / date / datetime / enum / link / file / object / list）。⚠️ 其中 **enum / list 的类型参数控件无设计稿依据**，形制为推导（[spec-ui.md §4](spec-ui.md)）——补稿后该节作废并需回头对齐，本条的**行为**不受影响、**样式**可能返工 |
| A2 | `fieldKey` 保存时做项目内唯一性校验，重复则禁止保存并给出错误提示 |
| A3 | `fieldKey` 可随时修改，修改不断任何引用（关联走 `metaFieldId`） |
| A4 | `dataType` 可随时修改；已被引用时修改后弹出引用清单模态作影响提示 |
| A5 | number 类型：`precision` 取值 0–6，保存时按 precision 四舍五入（round half away from zero）后才落库 |
| A6 | number 类型：单位三态——无 / 纯标注（自由文本）/ 时间单位组（分钟·小时·天·周） |
| A7 | 校验规则按数据类型约束合法组合（如 `pattern` 只允许出现在文本类字段上），非法组合被 zod 层拒绝 |
| A8 | 空输入按 `01 §2.5` 归一化：text/multiline trim 后为空 → `null`；number/date/datetime 清空 → `null`；enum 选「未选择」→ `null`；boolean 三态「未设置」→ `null` |
| A9 | 数据落 IndexedDB，**刷新页面后数据仍在** |
| A10 | `MetaField` 带 `createdAt` / `updatedAt`（UTC ISO 8601）：新建时两者相同，每次保存刷新 `updatedAt`；`docs/01 §2` 的接口定义同步回写 |

### B. 列表态

| # | 条件 |
|---|---|
| B1 | 筛选三项可用：名称/字段键（Input）、数据类型（Select）、引用状态（Select：全部 / 已被引用 / 未引用）；`[重置] [查询]` 位于第 1 行第 4 列 |
| B2 | 表格六列齐全：名称（弹性宽）/ 字段键 200 / 数据类型 140 / 被引用 120 / 更新时间 180 / 操作 120；全部左对齐 |
| B3 | 「更新时间」按 `YYYY-MM-DD HH:mm` 渲染 |
| B4 | 「数据类型」列为 Tag 型徽章 |
| B5 | 「被引用」列：有引用时显示「N 个模型」且可点，无引用时显示「未引用」且不可点 |
| B6 | 整行可点进入编辑抽屉；「被引用」单元格与操作列按钮点击**不触发**行点击 |
| B7 | 表格不开列排序、不开列筛选 |
| B8 | 无数据时展示空态，文案「暂无元字段数据，刷新列表」 |
| B9 | 工具条左「元字段列表」，右主按钮「新增元字段」 |

### C. 编辑抽屉

| # | 条件 |
|---|---|
| C1 | 抽屉宽 560、全高；头部为字段名 + 引用计数徽标（**纯展示不可点**） |
| C2 | 字段序：字段键 → 名称 → 数据类型 → 类型参数 → 校验规则构建器 → 默认值 → 帮助文字 |
| C3 | 必填项校验不过禁止保存。**恒必填**：字段键、名称、数据类型。**类型参数按 `dataType` 条件必填**（显隐矩阵见 [spec-ui.md §4.3](spec-ui.md)）：`number` → 精度、单位模式（单位模式选「时间单位组」时**具体单位同为必填**）；`enum` → 选项行至少 1 项且 `value` 项内唯一非空；`list` → 子项类型。其余 8 种类型无类型参数 |
| C4 | 默认值、帮助文字、校验规则为选填 |
| C5 | 底部动作条右侧 `[取消] [保存]`；**抽屉内无删除按钮** |
| C6 | 「新增元字段」走同一抽屉的空白态，标题为「新增元字段」 |
| C7 | 校验规则构建器：「添加规则」下拉只列出该数据类型的合法规则；每行 = 规则名 + 参数控件 + 删除 |
| C8 | 默认值控件按类型渲染，且皆含「未设置」态（boolean 为三态控件） |

### D. 浮层

| # | 条件 |
|---|---|
| D1 | 引用清单模态：装表格，列 = 引用方名称 / 类型 / 位置说明；只读；底部**仅一个「关闭」**且取主按钮 |
| D2 | 引用清单有且仅有两个入口：表格「被引用」可点单元格、抽屉内改「数据类型」时的影响提示 |
| D3 | 删除确认为**确认型**：图标 `ExclamationCircleFilled` 取 `colorError`，标题「确认删除元字段」，内容「删除后不可恢复。该元字段当前未被引用，可安全删除。」，`[取消] [确认]` |
| D4 | 被引用时删除按钮**禁用** + Tooltip「被 N 个节点模型引用，解除引用后方可删除」，**点不开确认框** |

### E. 外壳

| # | 条件 |
|---|---|
| E1 | 左菜单六项齐全，可收起 |
| E2 | PageHeader 标题「元字段」由 `menus` 配置按当前 path 匹配得出，**页面本身不参与标题** |
| E3 | 路由为 `/#/meta-fields`（`createHashRouter`） |
