| ID | 覆盖 | 用例 |

| TC-A1 | A1 | 对 11 种 `dataType` 各构造一个最小合法 `MetaField`，zod `parse` 全部通过；构造第 12 种非法值 `"unknown"`，`parse` 抛错 |
| TC-A2 | A2 | 库中已存在 `fieldKey = "title"`，再存一个同 `fieldKey` 的新元字段 → 拒绝并返回唯一性错误；改为 `"title2"` → 成功 |
| TC-A3 | A3 | 已有元字段 `mf_x` 被 `nodeSchemas` 引用，改其 `fieldKey` 后：引用关系仍指向 `mf_x`（引用计数不变），新 `fieldKey` 已生效 |
| TC-A4 | A4 | `dataType` 由 `text` 改为 `number` 后保存成功，且 `numberConfig` 缺失时 zod 报错（number 必须带 `precision`） |
| TC-A5 | A5 | `precision = 2` 时存入 `1.005` → 落库为 `1.01`（round **half away from zero**，非 banker's rounding）；`precision = 0` 时 `2.5` → `3`、`-2.5` → `-3` |
| TC-A6 | A6 | 单位三态各构造一例：`unit` 缺省 / `{kind:"label",text:"次"}` / `{kind:"grouped",unitGroupId:"time",code:"hour"}` 均通过；`{kind:"grouped"}` 缺 `code` 报错 |
| TC-A7 | A7 | `dataType = "number"` 带 `{rule:"pattern"}` → zod 拒绝；`dataType = "text"` 带同规则 → 通过。反向：`text` 带 `{rule:"min"}` → 拒绝 |
| TC-A8 | A8 | 逐类型验空值归一：`text` 输入 `"  "` → `null`；`number` 清空 → `null`；`enum` 选「未选择」→ `null`；`boolean` 选「未设置」→ `null`；**`list` 删光子项 → `[]` 而非 `null`** |
| TC-A9 | A9 | 经 `IndexedDBAdapter` 写入 3 条 → 重建 adapter 实例（模拟刷新）→ `list()` 仍返回 3 条且字段完全相等 |
| TC-A10 | A10 | 新建时 `createdAt === updatedAt`；间隔后更新一次 → `updatedAt > createdAt` 且 `createdAt` 未变；两者均为 UTC ISO 8601 |

## C. 编辑抽屉（8 条 · 组件）

| ID | 覆盖 | 用例 |
|---|---|---|
| TC-C1 | C1 | 抽屉 `width === 560`；头部渲染字段名 + 引用徽标；**徽标不可点**（无点击回调）；引用数 0 时徽标文案为「未引用」 |
| TC-C2 | C2 | 表单项 DOM 顺序为：字段键 → 名称 → 数据类型 → 类型参数 → 校验规则 → 默认值 → 帮助文字。`dataType = number` 时类型参数展开为 精度 → 单位模式 → 具体单位 |
| TC-C3 | C3 | **恒必填**：清空「字段键」/「名称」/「数据类型」任一 → 阻止提交并标红。**条件必填**：`number` 时清空「精度」或「单位模式」→ 阻止；单位模式 = 时间单位组而不选具体单位 → 阻止；`enum` 时选项行为空 → 阻止；`enum` 时两行 `value` 重复 → 阻止；`list` 时未选子项类型 → 阻止。**反向**：`dataType = text` 时表单**不渲染**精度/单位模式，且不因其缺失而阻止保存。全部填齐 → 保存回调被调用 |
| TC-C4 | C4 | 默认值、帮助文字、校验规则三项全空 → 保存成功（不报必填） |
| TC-C5 | C5 | 底部动作条渲染 `[取消] [保存]` 且**不含任何删除按钮** |
| TC-C6 | C6 | 从「新增元字段」入口打开 → 全部字段为空、标题为「新增元字段」；从行「编辑」打开 → 字段回填该行数据 |
| TC-C7 | C7 | `dataType = text` 时「添加规则」下拉含 `minLength`/`maxLength`/`pattern`，**不含** `min`/`max`/`minItems`；切到 `number` 后含 `min`/`max`，**不含** `pattern`。添加一条规则 → 出现 RuleRow；点行内删除 → 该行消失 |
| TC-C8 | C8 | 默认值控件按类型切换：`boolean` → 三态控件且含「未设置」；`date` → 日期选择器且可清空；`text` → 输入框 placeholder「未设置」 |

> **补充（`08 §8.1` 脏标记）**：编辑后不保存直接关闭抽屉 → 弹未保存确认框。并入 TC-C5 断言。
