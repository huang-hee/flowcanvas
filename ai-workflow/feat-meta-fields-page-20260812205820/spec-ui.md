## 4. enum / list 类型参数控件（⚠️ 无设计稿依据）

**本节全部为推导，非设计定稿。** 形制取自 §1.2 的 RuleRow——同为「一行一条 + 删除 + dashed 添加」的重复项编辑器，用同一形制可避免页内出现第二套视觉语言。**待 Figma 补稿后以稿为准，本节作废。**

### 4.1 enum 选项行（`dataType = enum` 时出现，必填至少 1 项）

```
┌─────────────────────────────────────────────┐
│ [value: Input mono]  [label: Input]     [🗑] │  ← OptionRow，底 --fill-muted，高 32
├─────────────────────────────────────────────┤
│ + 添加选项                                    │  ← dashed block
└─────────────────────────────────────────────┘
```

| 项 | 规格 |
|---|---|
| 容器 | 同 RuleRow：底 `--fill-muted`、圆角 6、高 32、`pl 12 / pr 4`、行距 8 |
| `value` | `Input`，`text/mono`，占行宽 40% |
| `label` | `Input`，`text/body`，占行宽 60%，与 value 间距 `space/sm`(8) |
| 删除 | icon-only text 24×24，`DeleteOutlined` 14px |
| 添加 | dashed block 按钮 + `PlusOutlined`，文案「添加选项」 |

**校验**：`value` 项内唯一、非空；至少一项。对应 `01 §2` 的 `enumOptions: { value, label }[]`。

### 4.2 list 子项类型（`dataType = list` 时出现，必填）

单个 `Select`，宽度跟随 `Form.Item`。选项 = `FieldDataType` 全集 **含 `object`**（`01 §2` 的 `itemType` 注明「含 "object"，此时内部结构在节点组装层组合」）。

- 选 `object` 时**不展开任何子结构编辑**——`09 §2.4` 已明确「不做：object / list(object) 内部结构编辑」。
- `extra` 文字：「选 object 时，内部结构在节点模型页的子组装中定义」。

### 4.3 类型参数区的显隐矩阵

| `dataType` | 出现的类型参数 |
|---|---|
| `number` | 精度 ✓、单位模式 ✓、具体单位（单位模式 = 时间单位组时） |
| `enum` | enum 选项行（§4.1） |
| `list` | 子项类型（§4.2） |
| 其余 8 种 | 无类型参数 |

**切换 `dataType` 时**：已填的类型参数值清空（换类型即语义重释，`01 §2.7` 同级处理）；若该元字段已被引用，按 `09 §2.4` 弹引用清单模态作影响提示。
