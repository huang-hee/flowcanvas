# 05 · 产品规格

> 文档状态：正式方案 v1.1（2026-08-09 页面交互评审定稿，本版重写导航骨架、交互范式与视觉语言）
> 依赖：[01](01-领域模型与协议.md)–[04](04-存储与同步规范.md)。v4 暗色视觉语言已废止（00 决策 19）；「配置中心」更名「控制台」（00 决策 18）。

## 1. 信息架构与导航

**单项目应用**：项目 = 应用本身，UI 无项目层（无项目列表、无切换器）；`.flowpack` 导入导出即工作空间边界；04 协议内部保留固定 `projectId` 以兼容未来多项目。

两个页面外壳：

- **控制台**（配置域）：左右撞色布局——左侧深色菜单栏（固定展开约 240px，MVP 不做收起态），右侧浅色主操作区。左菜单六项：`仪表盘 / 元字段 / 节点模型 / 驱动方案 / 流程页面 / 实例列表`。顶栏：左侧应用名「FlowCanvas」，右侧导出 / 导入 `.flowpack` + 同步状态徽标（阶段二占位）。**MVP 无设置页**。
- **执行实例页**：独立标签页打开，URL 可复制、可收藏；**不出现控制台菜单**；配置快照以只读抽屉查看，顶栏提供「控制台」入口（见 §9.1）。

> 实例列表进入控制台菜单是对 v4「配置导航只含四页」硬约束的正式修订（00 决策 17）；隔离的本意——执行页不出现配置导航——保持不变。

### 1.1 路由（hash 路由）

```text
/#/dashboard          仪表盘（首屏）
/#/meta-fields        元字段
/#/node-schemas       节点模型
/#/drivers            驱动方案（只读）
/#/flows/<flowId>     流程画布
/#/runs               实例列表
/#/run/<runId>        执行实例页（独立外壳）
```

hash 路由零部署配置。数据在 IndexedDB，URL 仅在**同一浏览器**有效；跨设备打开依赖阶段二云同步。

## 2. 全局交互范式

### 2.1 保存模型（混合）

- **表单类显式保存**（元字段、节点模型、驱动绑定）：编辑产生脏标记，点保存落库；「必需槽位未解析禁止保存」由保存按钮禁用逻辑承载。
- **流程画布即时自动保存**：增删节点、连线、拖动位置即时写入草稿——草稿允许不完整，发布门全量校验兜底。
- 关闭带脏标记的表单页给未保存确认。

### 2.2 撤销/重做

画布结构操作支持 `Ctrl+Z / Ctrl+Y`（会话级内存栈，不持久化）；表单类不做 undo（显式保存天然可弃改）。

### 2.3 校验反馈三级

1. **字段级**：失焦即时标红（必填、正则、类型）。
2. **对象级**：点保存时汇总（驱动槽位完整性等）。
3. **流程级**：发布时全局校验面板（六层全跑）。

画布上节点校验问题实时显示角标（如缺驱动输入）。

### 2.4 弹层四级分工

| 载体 | 用途 |
|---|---|
| 整页 | 控制台六页、执行页 |
| 抽屉（右侧滑出） | 只读快照查看、节点详情速览、引用清单 / 影响提示 |
| 模态 | 发布校验与确认、冲突三选一、破坏性确认（删节点、删实例、断开云）、新建实例 |
| Toast | 保存成功、同步完成等瞬时反馈，**不承载错误详情** |

判据：需要对照上下文看的用抽屉，需要打断决策的用模态。

## 3. 仪表盘（首屏）

四个模块，按优先级排布：

1. **流程卡片区**：每条流程一张卡——名称、节点数、校验状态徽标、最近发布版本号（含 `note` 摘要）、「编辑 / 发布」入口。
2. **执行概况区**：进行中实例数、临期 / 超时警示计数（点击穿透到对应实例）、最近活跃实例快捷入口。
3. **快捷操作**：新建流程 / 新建元字段 / 导入 `.flowpack`。
4. **同步状态**（阶段二补位）。

「配置数据流对象关系图」（v4 首版核心稿）**不进 MVP**，记为未来**门户页面**组件；v4「数据流必须可见连线呈现」的硬约束随之顺延。

## 4. 元字段页

- 左侧元字段列表（按类型筛选）；中央编辑区：稳定键（创建后锁定）、名称、数据类型、枚举选项 / 列表子结构、校验规则构建器（[01 §2.1](01-领域模型与协议.md) 声明式规则，表单化）、默认值、帮助文字。
- 右侧「使用情况」：引用本字段的节点模型与流程草稿清单（活引用影响提示入口）。
- **被引用禁删**：删除按钮在存在引用时禁用并展示引用清单。

## 5. 节点模型页

- 左侧 NodeSchema 列表；中央字段集合表（引用元字段、覆盖展示名 / 必填 / 默认值、拖拽排序）；右侧结构预览与引用流程。
- 页签：**字段结构 / 默认驱动 / 使用情况**。
- 默认驱动页签四步编辑：
  1. 选择驱动方案（时间 / 条件 / 事件 / 不使用——不使用是合法选项）；
  2. 逐槽位选择来源（field / system / constant；system 为受限枚举 + 偏移表单，无手写表达式）；
  3. 类型与完整性校验（必需槽位未全部解析时**保存按钮保持禁用**）；
  4. 人类可读规则预览（field 来源显示字段名而非具体值，如「前序组就绪次日开始，持续〈预计时长〉，提前 24 小时提示临期」）。
- 完成策略选择器 MVP 只开放「人工完成」；confirm / auto 置灰并标注「阶段三开放」。

## 6. 驱动方案页（只读）

- **只读展示**内置 DriverDefinition，无任何可配置项（将来出现真实可配置项如全局默认临期阈值时再单独设计）；不在此绑定节点模型。
- 三张方案卡：输入契约（槽位、类型、允许来源、默认来源）、输出契约（能产出的生命周期与关注状态）、auto 完成能力（标注阶段三）、使用数量。
- 事件驱动明确标注「应用内事件 + 手动记录」「外部日志导入（阶段三）」「关闭期间重开追算」「不支持公网 Webhook」。

## 7. 流程页面（画布）

- **建节点**：左侧节点模型库**拖拽入画布**；从已有节点输出端口**拉线到空白处松手 → 弹出节点模型选择器**快速续建。节点引用节点模型，不复制字段定义。
- **连线**：端口拖拽连线，默认关系 = **必经**；点击边后在检查器或边上下文菜单切换为可选 / 参考（线型 + 文字图例双通道表达）。
- **删除**：选中后 Delete 键或检查器按钮，删节点连带删其连线，走确认模态。MVP 单选。
- **保存**：结构与位置即时自动保存；位置写入 `viewState` 仓（[04 §2.1](04-存储与同步规范.md)），**不入流程定义与快照**。
- 节点检查器：字段集合预览、驱动解析结果、`inherit / override / none` 切换；**override 打开完整绑定编辑器**，不允许部分覆盖。
- 多前序汇聚显示 joinPolicy 徽标（MVP 固定 all）；子流程节点显示下钻入口徽标（阶段二）。
- 校验面板：缺失驱动输入、类型错误、孤立节点、入口错误、必经环；发布入口在此，全绿才能发布。
- 发布模态分步：① 校验运行 → ② 结果列表（错误阻断 / 警告放行）→ ③ 确认发布 + **可选版本说明**（`FlowVersion.note`）→ ④ 成功态（「打开实例列表 / 创建实例」CTA）。

## 8. 实例列表页

- **按流程快照分组**：组头 = 流程名 + vN + 版本说明；组内实例行：实例名、生命周期汇总（进行中 x · 受阻 x）、主线完成度、关注警示（临期 / 超时计数）、创建时间、最近活动、操作。
- 过滤页签：**进行中 / 已归档**。
- 操作：**打开**（新标签页）、**归档 / 恢复**、**永久删除**——仅对已归档实例开放，双确认模态（输入实例名），物理删除该实例全部事件日志；不提供任何日志级修改。
- **新建实例**：模态选择流程快照（默认最新版）→ 命名 → 创建并在新标签页打开。

## 9. 执行实例页

### 9.1 顶栏

```text
[FlowCanvas 标识] [实例名(主标题)] [流程名 · vN 徽标]   [必经完成度 3/7] [⚠ 临期1 · 超时0] [同步徽标] [控制台] [⋯]
```

- **流程名 + vN 徽标**：点击打开只读快照抽屉（含版本说明），取代旧「查看配置快照」按钮。
- **完成度与警示计数**：主线进度 + 临期 / 超时计数，点击警示聚焦对应节点。
- **「控制台」按钮**：当前标签跳转控制台仪表盘（不再设「返回实例列表」）。
- **更多菜单**：归档实例、导出 `.flowpack`、复制实例链接。

### 9.2 布局

左侧深色栏：本实例节点列表（状态徽标）或缩略流程；中央：运行流程图与当前任务；右侧：当前任务卡 + 节点详情。

### 9.3 当前任务卡（右栏顶部固定）

聚焦规则（纯派生，由 `RunProjection` 计算）：

1. **受阻**节点（要补字段，最紧迫）；
2. 关注状态为**超时 / 临期**的进行中节点；
3. 最早激活的**进行中**节点；
4. 都没有时显示**下一个等待开始**节点（含预计开始时间）。

同级多个取最早激活者，卡片提供「下一个」切换。内容：节点名、生命周期 + 关注徽标、关键运行字段摘要、主操作（受阻 → 补值；进行中 → 完成；等待 → 查看）、次操作（跳过 / 详情）。

### 9.4 节点详情（右栏）

区块顺序：**运行字段**（可编辑，保存粒度落 `field.valueSet`）→ **驱动计算**（只读解释：槽位解析值、判定结果）→ **生命周期时间线**（由日志派生）→ **执行证据**（`evidence.attached` 事实：文本备注 + 链接，二者至少其一；文件附件延后）。

### 9.5 核心行为

- 状态呈现**必须同时使用文字、图标和颜色**三通道；生命周期与关注状态并列展示，互不覆盖。
- 完成开始元节点后：无延迟人工节点立即进行中；配置次日开始的时间节点进入等待开始。
- 时间节点支持模拟正常 / 临期不足一天 / 已超时（虚拟 now，纯展示，不写日志）。
- 运行字段缺值 → 受阻 + 缺失字段清单 + 补值入口；补值后重算恢复。
- 完成 / 跳过 / 撤销完成 / 撤销跳过入口（撤销是新事实）。
- 手动记录事件入口：选择事件类型 + 可选备注，供事件驱动节点感知。
- 主线完成度与可选完成度分开展示。

### 9.6 同步状态徽标（阶段二）

04 `SyncStatus` 九态的完整视觉映射：

| 状态 | 呈现 |
|---|---|
| `disconnected` | 不显示徽标（未连接云） |
| `idle` / `synced` | 灰绿 ·「已同步」 |
| `dirty` | 琥珀点 ·「待同步」 |
| `syncing` | 旋转 ·「同步中」 |
| `offline` | 灰 ·「离线」 |
| `conflict` | 红 ·「冲突」→ 点击进三选一 |
| `auth_expired` | 琥珀 ·「重新连接」 |
| `error` | 红 ·「同步失败」→ 点击看详情 |

## 10. 视图协议

- 视图 = 数据的展示形式；**内核输出与视图解耦**：执行页视图消费 `RunProjection`，编辑画布消费 `FlowDefinition`，都不反向写入语义。
- 视图不得：改写边关系语义、改写参与类别、保存运行状态、执行完成动作以外的状态变更。
- MVP 内置两个视图：**编辑画布**与**默认执行视图**。多视图切换不进 MVP；将来加视图 = 实现一个 ViewRenderer：

```ts
interface ViewRenderer {
  viewId: string;
  name: string;
  capabilities: { manualPositioning: boolean; subflowDrilldown: boolean };
}
```

- 节点位置、视口、折叠状态等**视图状态**存 `viewState` 仓，不写入流程定义与快照。

### 11.3 排版与形态（沿用 v4）

- 中文字体 `Inter, PingFang SC, Microsoft YaHei, sans-serif`；稳定键、ID、结构预览用 `IBM Plex Mono, monospace`。
- 控件圆角 10px，对象卡与节点 14px，浮层 18px；克制阴影、清晰 1px 边框。
- 禁止蓝紫渐变、装饰性衬线字体、库存图片和营销页布局。
- 桌面优先：最优 1600+，最小支持宽度 1280（低于出横向滚动，不做布局降级）；移动端适配阶段三。

## 12. 硬约束

1. 元字段 = 字段定义；节点模型 = 字段集合；术语全站统一（[00 §2](00-术语表与总览.md)）。
2. 节点可以没有驱动器；有驱动器时所有必需输入必须完整解析且类型兼容，否则禁存禁发（由表单保存按钮承载）。
3. 每个流程节点最多一个主驱动。
4. 流程页面不保存运行状态；配置工作止于发布快照。
5. 执行实例使用独立页面外壳（独立标签 + URL），不出现控制台菜单。
6. 状态永远由重算得出，UI 不直接改状态字段；一切用户操作落为事件日志事实。
7. MVP 完成一律人工；confirm / auto 置灰示意，阶段三开放。
8. 浅色主题唯一；深侧栏撞色语言全站统一。
