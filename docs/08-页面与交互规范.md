# 08 · 页面与交互规范

> 本文档管**结构与行为**：面板原语、外壳、交互范式、逐页 UI 设计。
> 依赖：[05-产品规格](05-产品规格.md)（页面有什么、能干什么）、[07-主题与设计系统](07-主题与设计系统.md)（一切数值与 token）。
> **分工判据：值归 07，结构与行为归 08。** 本文一律引用 07 的 token 名与档位名，**不复制数值**。

## 1. 设计原则

- **仅浅色主题，不做明暗切换**；全站为暖色浅底体系，靠明度分层而非撞色——chrome（侧栏）最深、内容区居中、面板最亮。
- 状态一律**文字 + 图标 + 颜色**三通道，色弱可用。
- 克制阴影、清晰 1px 边框；禁止蓝紫渐变、装饰性衬线字体、库存图片和营销页布局。
- 桌面优先：最优 1600+，参考宽度 1280；**最小宽度按页定义**，窄于该页下限时由**面板内部自行滚动**（横向亦然，如宽表格在表格面板内横滚），不做布局降级；移动端适配阶段三。
- **组件库优先**：能由 antd 主题 token 达成的一律走 token，不写自定义样式；偏离登记进 [07 §6](07-主题与设计系统.md)，自研组件登记进本文 §5.2。

## 2. 面板原语与组合规则

全站一切容器——侧边栏、主区、列表面板、编辑面板、执行页三栏、抽屉、模态——都是**同一原语的配置差异**，不存在「页面类型学」。

### 2.1 面板原语 Panel

- **高度撑满父容器**；纵向三段式：
  - **头部**：固定不滚，可省略；
  - **主体**：滚动区，**必有**；
  - **底部**：固定不滚，可省略。
- 头 / 底与主体之间以 1px `--border` 分隔线相隔，分隔线**横贯面板全宽**。
- 头、底高度不设全局定值，由内容物按 padding 规范撑开（外壳的侧栏头与右侧头部除外，见 §3）。
- **宽度模式**只有两种：固定值 或 flex 占满剩余。

### 2.2 皮肤两档

| 皮肤 | 规格 |
|---|---|
| `card` | 白底 `--surface` + 1px `--border` + 自有面板圆角 `radius/panel` + 面板级阴影 + 内 padding `space/inner` |
| `plain` | 无底色无边框的结构容器（如右侧主区） |

### 2.3 组合规则

- 横向组合**最多三栏**；相邻面板间距 `space/panel-gap`。
- 承载面板的容器 padding `space/inner`。
- 允许嵌套（面板主体内再放横向面板组合），实践深度 **≤ 2**。
- 纵向堆叠时：高度按内容的面板取 hug，主面板取 flex 撑满剩余，间距同 `space/panel-gap`。

### 2.4 浮层同构

抽屉与模态是面板原语的**浮层形态**：继承三段式与头 / 底固定规范，差异仅在圆角档、遮罩与定位。弹层四级分工（§4.4）只管**用途归属**，结构规范不再单写。

| 浮层 | 尺寸 | 定位 |
|---|---|---|
| 抽屉 Drawer | **一律全高**（贴视口右缘，自 y=0 至底，覆盖 Sidebar 与 PageHeader）；宽度逐页自定义 | 右侧滑出 |
| 模态 Modal | 宽高均可逐页自定义，但不得超出视口可用尺寸 | 见下方定位规则 |

**模态定位规则**：模态高度 **≤ 视口高度 50%** 时，距视口上边界 **20%**（高位置，视线焦点处）；**其余情况一律垂直居中**。

**圆角**：见 [07 §3.2](07-主题与设计系统.md)——悬浮浮层四角取浮层档；**抽屉仅左侧两角取浮层档，贴视口边一侧为直角**（贴边角做圆会在视口边缘露出缺口）。

**遮罩**：色值取 antd `colorBgMask`；范围与层级不另立规范，按 antd 默认行为，逐页只声明尺寸。

**结构与用法通则**（抽屉与模态共用）：

- **三段式**：头部（标题 + 关闭）与底部（动作条）固定，**中间区域滚动**。
- **尺寸不写死在规范里**：宽高一律由组件 prop 传入（`Drawer width` / `Modal width`），逐页声明。
- **按钮配置与文案走 prop**；两个按钮都显示时布局为 **`[取消] [确定]`**（取消在左、主操作在右），右对齐。
- **底部变体 · 分页型**：当浮层主体装的是表格时，底部为 **flex 两端对齐**——左侧分页控件、右侧动作按钮。

**确认模态**（破坏性操作专用）——沿用 antd `Modal.confirm` 的原生布局，不自造：

```
┌──────────────────────────────────┐
│ ⚠  确认删除元字段                 │ ← 第一行：图标 + 标题（同一行）
│    删除后不可恢复。该元字段当前     │ ← 第二行：具体确认内容
│    未被引用，可安全删除。          │
│                    [取消] [确认]  │ ← 底部动作条
└──────────────────────────────────┘
```

- **两行结构**：图标与标题同处第一行，确认内容另起一行；图标默认 `ExclamationCircleFilled`，破坏性操作用错误色。
- **底部** `[取消] [确认]` 右对齐；**两个按钮可能不全展示**（如纯告知型只留一个），走 `footer` / `okButtonProps` / `cancelButtonProps` 定制。
- 其余走 antd 默认：宽 416、`closable: false`、`okType: primary`。
- 破坏性动作（删除元字段 / 删节点 / 删实例 / 断开云 / 导入替换工作空间）**一律经此模态**，不做无确认的直接删除。

### 2.5 通用表格页布局

配置对象的列表页一律采用本型；**筛选面板与分页两部分皆可省**，没有筛选项或不分页的表格页由本型退化而来。

```
PageBody（padding space/inner）
┌─ 筛选面板 card · flex · 高 hug ──────────────────────────────┐
│ [名称 🔍] [数据类型 ▾] [引用状态 ▾]           [重置] [查询] │
└──────────────────────────────────────────────────────────────┘
                    ↕ space/panel-gap
┌─ 表格面板 card · flex · 高撑满 ──────────────────────────────┐
│ 元字段列表                                   [+ 新增元字段]  │ ← body 顶部工具条
│  ─────────────────────────────────────────────────────────   │   （随内容滚走）
│ │名称    字段键    类型   被引用   更新时间   操作         │ │ ← thead sticky
│ │…                                          （滚动区）     │ │
│  ─────────────────────────────────────────────────────────   │
│ 共 6 条                [20/页 ▾] ‹ 1 2 › 跳至 [ ] 页        │ ← sticky bottom
└──────────────────────────────────────────────────────────────┘
```

**表格面板既无 `panel.header` 也无 `panel.footer`**——工具条、表格、分页器全部位于面板 `body` 内：

| 段 | 规格 |
|---|---|
| 工具条 | 位于 body 顶部；左 = 列表标题（`text/body-strong`），右 = 主按钮。**随内容滚走**，不吸顶 |
| 表格 | 表头 `sticky` 开启——滚动时表头吸到**表格面板顶部**。**默认配置**：`size="medium"`、`bordered={false}`、**列不带 `sorter` 与 `filters`**；确有需要的列由该页规范**显式声明**，不声明即不开 |
| 分页器 | 跟随表格（属 `Table` 的 `pagination`，非面板底部段），CSS `position: sticky; bottom: 0`——**内容短时跟在表格后面，内容超出面板时贴住底边**；sticky 保留文档流占位，最后一行滚到其上方而**不被遮挡** |

**操作列**：固定为 **`[编辑] [删除]` 两个文字按钮**，不用 `⋯` 折叠菜单。删除**一律走确认模态**（§2.4）；被引用时按钮禁用 + Tooltip 说明原因（§4.4）。

**可点单元格**：承载「跳转 / 打开浮层」语义的单元格（如「被引用」列点开引用清单模态）用**链接态样式**——文字取 `--primary-hover`、hover 出下划线、鼠标为 pointer；纯展示单元格保持 `--text`，不得混用。

**分页器参数**：`total` 传总条数（「共 N 条」由此渲染）；`showSizeChanger` 与 `showQuickJumper` **均开启**；默认每页 **20**，档位 `10 / 20 / 50 / 100`。
**分页器排布**：**总数在最左、分页控件在最右**（两端对齐）——需一处全站复用的自定义样式（[07 §6](07-主题与设计系统.md) 偏离项 6）。

**空态 / 错误态 / 加载态**：三态都发生在**表格区内部**——工具条、筛选面板、表头**保持可见**（否则用户无从重置筛选或新建）。

| 态 | 呈现 |
|---|---|
| 空数据 | 空态插画（§5.2，高 160，与文案间距 `space/inner`）+ **单行**文案「暂无〈对象名〉数据，刷新列表」，「刷新列表」为文案内的**内联链接**（`--primary-hover`），点击**重新发起请求** |
| 请求异常 | **同一张插画** + 单行文案「请求出错，重新请求」，「重新请求」同为内联链接，点击重新发起请求 |
| 加载中 | `Table` 的 `loading` prop（表格区遮罩 + 转圈） |

- 文案**一律单行不换行**，动作是文案里的内联链接，**不做独立按钮**。
- **「筛选后无结果」不单独区分**，与空数据同一呈现与文案。

### 2.6 筛选表单规范

- **内联 label 用控件的 `prefix` 属性实现**，不另起独立 label 元素——`Input` 与 `Select` 均支持 `prefix`。标签文字取 `text/label` + `--text-secondary`。
- **每一项必须有 placeholder**：输入类为「请输入〈标签〉」，选择 / 日期类为「请选择〈标签〉」。
- **布局 grid + 自适应**，默认**一行四列**，各列等宽；**行间距 `space/sm`、列间距 `space/md`**。
- **按钮块永远位于最后一行最右侧，占据该行剩余列**；筛选项数正好填满整行（4 的整数倍）时，按钮**另起一行占满 4 列**并右对齐。
  - 3 项 → 第 1 行第 4 列（占 1 列）
  - 4 项 → 第 2 行（占 4 列）
  - 5 项 → 第 2 行后 3 列
- 按钮为 `[重置] [查询]`，查询为主按钮。**不做「展开更多筛选」**——真出现塞不下的页面再加，不破坏本型结构。

### 2.7 实例对照

| 实例 | 头部 | 主体（滚动） | 底部 | 宽度 / 皮肤 |
|---|---|---|---|---|
| 侧边栏 | logo + 应用名 | 菜单 | 收起 / 展开按钮 | 固定 `size/sidebar-w`（收起 `size/sidebar-w-collapsed`）/ chrome 底（§3.2） |
| 右侧主区 | 页面头部 | 页面内容 | 省略 | flex / `plain` |
| 列表页 · 筛选面板 | 省略 | 筛选表单 | 省略 | flex · 高 hug / `card` |
| 列表页 · 表格面板 | 省略 | 工具条 + 表格 + 分页（§2.5） | 省略 | flex · 高撑满 / `card` |
| 编辑抽屉 | 对象名 + 引用徽标 | 表单 | 动作条 | 全高浮层 · 宽逐页定 / `card` |
| 详情二级页 | 面包屑 + 引用徽标 | 分区内容 | 操作条 | flex · 撑满 / `card` |
| 画布页 | 页面头部 | 画布（不滚动，平移缩放；检查器为浮动 `card` 面板） | 省略 | flex / `plain` |

## 3. 控制台外壳

### 3.1 结构与区域命名

外壳只有**两种**：**控制台外壳**（六页共用，本节）与**执行页外壳**（独立标签，[05 §9](05-产品规格.md)）。404 / 加载失败等以控制台外壳的空 PageBody 表达，不另立外壳。

> **执行页外壳继承本规范全部通则**——面板原语（§2）、色板与文字层级（07）、浮层规则（§2.4）、「页面级不滚、只在面板主体内滚」、区域命名术语。它不是另一套设计语言，只是**槽位内容与栏位比例不同**。差异部分（顶栏槽位构成、三栏宽度、节点列表形态）与页面内容强耦合——执行页左栏装的是本实例节点列表，属**内容**而非导航，与控制台的 `Sidebar` 性质不同，故取 `card` 皮肤而非 chrome 底——具体随该页评审时定义（§6）。

```
┌───────────────────────────────────────────────────────────┐ Shell
│ ┌───────────┬───────────────────────────────────────────┐ │
│ │ Sidebar   │ PageHeader            高 60 固定           │ │
│ │ 240 ⇄ 64  ├───────────────────────────────────────────┤ │
│ │ 全高       │ PageBody              padding 16          │ │
│ │           │   面板组合置于其中，各自内滚                │ │
│ │ Header 60 │                                           │ │
│ │ Body 菜单 │              ← 内容区，逐页定义             │ │
│ │ Footer 56 │                                           │ │
│ └───────────┴───────────────────────────────────────────┘ │
│   Overlays  抽屉 / 模态 / Toast（§2.4）                    │
└───────────────────────────────────────────────────────────┘
```

**区域命名为规范术语**，逐页规范一律使用下表词汇，不得另造说法：

| 术语 | 指代 |
|---|---|
| `Shell` | 整个外壳（含以下全部） |
| `Sidebar` / `Sidebar.Header` / `Sidebar.Body` / `Sidebar.Footer` | 左侧栏及其三段 |
| `MainColumn` | 右列（PageHeader + PageBody） |
| `PageHeader` | 右列顶部固定条 |
| `PageBody` | 右列内容区 —— **逐页定义的就是这里** |
| `Overlays` | 抽屉 / 模态 / Toast 层 |

- 左右两栏：`Sidebar` **固定宽全高**，`MainColumn` flex 占剩余。
- **页面级永不滚动**，一切滚动（纵向与横向）发生在面板主体内。
- 代码实现：`Sidebar` 用 **`<Layout.Sider theme="light">`**（`collapsedWidth` 承载展开 ⇄ 收起），菜单用 **`<Menu theme="light">`**——**必须是 `light`**，chrome 配色填的是 antd 的浅色档；选中项左缘 3px 为登记偏离（[07 §6](07-主题与设计系统.md)）。

**头部内容一律派生，禁止页面回写**：静态标题来自路由配置（`handle.title` + `useMatches`），动态内容由外壳自行读 store；路由表同时供给侧栏菜单的图标与文字，杜绝菜单与标题不同步。

### 3.2 侧边栏

| 段 | 规格 |
|---|---|
| 头部 | 高 `size/header-h`（与右侧头部同高，共享同一水平线）；logo 方块 + 应用名「FlowCanvas」；padding `space/inner` |
| 主体 | 六项菜单（图标 + 文字），内滚；四态见下 |
| 底部 | 高 `size/sidebar-footer-h`；仅放收起 / 展开按钮，**图标居中** |
| 右缘 | border-right 1px `--border` + 骨架级阴影，**投影贯穿全高**（[07 §4](07-主题与设计系统.md)） |

**侧栏是一根不被分割的立柱**——三段之间**不画横线、不投影**，靠底色连续读作整体；`FlowCanvas` 标题下方**不加分隔线**。

**菜单四态**（配色全部由 antd 浅色档承载，见 [07 §1.2](07-主题与设计系统.md)）：

| 态 | 底 | 文字 |
|---|---|---|
| 默认 | 无（透出 chrome 底） | `Menu/itemColor` |
| hover | `Menu/itemHoverBg`（半白） | 同默认 |
| **选中** | `Menu/itemSelectedBg`（**纯白**）+ **左缘 3px `--primary`** | `Menu/itemSelectedColor` |
| 禁用 | 无 | antd 默认 |

> 选中态靠「**变亮**」浮起（白底药丸），不靠变深——浅色 chrome 上变深会与 hover 混淆。左缘 3px 位于**侧栏最左边**（非药丸左侧），是登记偏离（[07 §6](07-主题与设计系统.md) 偏离项 1）。

### 3.3 收起态

- 宽度 `size/sidebar-w` ⇄ `size/sidebar-w-collapsed`，切换带 150ms 宽度过渡。
- 收起后：菜单仅留图标居中，hover 出 tooltip 显示名称；头部仅留 logo 居中，应用名隐去；底部按钮变为居中图标。
- 激活态左缘 3px `--primary` 两态都保留。
- **菜单图标**：六项各配一枚 `@ant-design/icons` 图标（收起态唯一辨识依据，展开态也显示）。
- **收起 / 展开按钮**：图标居中，展开态用 `MenuFoldOutlined`、收起态用 `MenuUnfoldOutlined`。
- 状态存 `appSettings` 跨会话记忆；**仅手动触发**，不做窄屏自动收起。

### 3.4 右侧头部与槽位规则

| 项 | 值 |
|---|---|
| 高度 | `size/header-h` 固定 |
| 底色 | **`Layout/headerBg` = 白**，与内容面板同色（侧栏比它深一档，形成 chrome / 内容的分层） |
| 内 padding | 左右 `space/inner` |
| 下缘 | border-bottom 1px `--border` + 骨架级阴影，**仅侧栏右侧那一段**——不越过侧栏（[07 §4](07-主题与设计系统.md)） |

槽位自左至右：

```
[页面标题区] ·············· [页面动作槽] │ [同步徽标] [⋯]
                                       ↑ 1px 分隔，高 20
```

- **页面标题区**、**页面动作槽**：内容逐页定义（§6）。页面动作槽**可空**——新建入口下沉表格面板工具条、保存下沉面板底部操作条，多数配置页此槽为空。
- **工作空间簇**永远钉在最右角，跨页位置恒定：同步状态徽标（[05 §9.6](05-产品规格.md) 九态映射）+ `⋯` 更多菜单（导出 / 导入 `.flowpack`；后续工作空间级操作也归此菜单）。

## 4. 全局交互范式

### 4.1 保存模型（混合）

- **表单类显式保存**（元字段、节点模型、驱动绑定）：编辑产生脏标记，点保存落库；「必需槽位未解析禁止保存」由保存按钮禁用逻辑承载。
- **流程画布即时自动保存**：增删节点、连线、拖动位置即时写入草稿——草稿允许不完整，发布门全量校验兜底。
- 关闭带脏标记的表单页给未保存确认。

### 4.2 撤销 / 重做

画布结构操作支持 `Ctrl+Z / Ctrl+Y`（会话级内存栈，不持久化）；表单类不做 undo（显式保存天然可弃改）。

### 4.3 校验反馈三级

1. **字段级**：失焦即时标红（必填、正则、类型）。
2. **对象级**：点保存时汇总（驱动槽位完整性等）。
3. **流程级**：发布时全局校验面板（六层全跑）。

画布上节点校验问题实时显示角标（如缺驱动输入）。

### 4.4 弹层四级分工

| 载体 | 用途 |
|---|---|
| 整页 | 控制台六页、执行页 |
| 抽屉（右侧滑出） | 轻对象编辑表单、只读快照查看、节点详情速览 |
| 模态 | **引用清单 / 影响提示**、发布校验与确认、冲突三选一、破坏性确认、新建实例 |
| Toast | 保存成功、同步完成等瞬时反馈，**不承载错误详情** |

判据：需要对照上下文看的用抽屉，需要打断决策的用模态。结构规范见 §2.4。

**引用清单统一为模态**：一个装表格的模态，列出引用方（哪些节点模型 / 流程草稿在用），底部**仅一个「关闭」按钮**。全站唯一载体——元字段、节点模型、流程的引用清单与改动影响提示都走它，**不做抽屉、不做就地展开、不做 Popover**。

**被引用禁删的呈现**：删除按钮**禁用**，并以 **Tooltip 说明禁用原因**（如「被 3 个节点模型引用，解除引用后方可删除」）。实现须给按钮套一层可接收事件的包裹元素（[07 §6](07-主题与设计系统.md) 偏离项 7）。

## 5. 组件约束

### 5.1 控件约束

- **一切表单一律用 `Form` + `Form.Item`**（含筛选表单、编辑抽屉、驱动绑定表单）——必填星号、校验触发、错误文案位置全部交给 Form 体系，不手工拼 label 与错误提示。
- boolean 运行字段用**三态控件**（未设置 / 是 / 否）；空输入保存 = 显式清空（[01 §2.5](01-领域模型与协议.md)）。
- 受阻补值表单**预填快照默认值**作建议（仅建议，保存才落日志）。
- `link` 仅 `https / http / mailto` 渲染为可点击链接，其余纯文本；helpText / description 一律纯文本（[01 §2.6](01-领域模型与协议.md)）。
- 完成度显示格式「完成 3/5 · 跳过 2」，分母不含跳过（[02 §8](02-状态引擎规范.md)）。
- 导入 = 替换工作空间的破坏性确认模态，含「已自动备份」提示（[04 §3](04-存储与同步规范.md)）。
- **状态徽章**：底 = tint（色阶第 1 阶）、**文字 = Active（第 7 阶）**、图标 = 基色（第 6 阶）——文字取深阶是无障碍要求（[07 §2.5](07-主题与设计系统.md)）。

### 5.2 自研组件清单

antd 覆盖不了、需自研的组件：条件树构建器、boolean 三态控件、画布节点卡与连线、驱动槽位绑定行、**空态插画**。规格随对应页面设计沉淀。

**空态插画**（全站空态与错误态共用一张）——源文件 [`docs/assets/empty-state.svg`](assets/empty-state.svg)：

- **造型**：一卷空白文档（左侧卷边、纸面留七条白色占位横线与一块方形占位）+ 柔和落影；一条**虚线自纸张右缘引出**（起点**贴住纸缘**，不留空隙），**绕一个小圈后向右上方扬起**，末端为实心箭头。语义为「数据卷走了」。
  > 入口段（纸缘 → 绕圈）须明显短于出口段（绕圈 → 箭头），约 132 : 258。**做法是把绕圈整体靠近纸张，而非缩短起点**——缩起点会让虚线脱开纸缘。
- **尺寸**：**高 160**（宽 215，比例 1.35）。`viewBox` 已裁到可见内容边界，故 160 即真实可见高度。
- **与文案间距** `space/inner`。
- **配色全取 07 §2.4 主色七阶，零新增 token**——插画内用六个 CSS 变量参数化：

  | 变量 | 值 | 来源 | 用途 |
  |---|---|---|---|
  | `--nd-paper-light` | `#D5C6B2` | `colorPrimaryBgHover`（阶 2） | 纸面渐变浅端、翻卷高光 |
  | `--nd-paper` | `#BCA58A` | `colorPrimaryBorder`（阶 3） | 纸面渐变中段 |
  | `--nd-paper-dark` | `#A28869` | `colorPrimaryBorderHover`（阶 4） | 纸面渐变深端、卷边起始 |
  | `--nd-arrow` | `#8A6F52` | `colorPrimary`（阶 6） | 虚线轨迹与箭头、卷边末端 |
  | `--nd-shadow` | `#D5C6B2` | `colorPrimaryBgHover`（阶 2） | 落影（径向渐变 α .48 → .12） |
  | `--nd-detail` | `#FFFFFF` | 白 | 纸面占位横线与方块 |

- **落地方式：全局只替换图，文案逐页给**。`ConfigProvider` 的 `renderEmpty` 在应用根部统一接管，所有吃 `Empty` 的组件一次性换成本插画；**全局不设 `description`**：

  ```tsx
  <ConfigProvider
    theme={flowcanvasTheme}
    renderEmpty={() => (
      <Empty image={<EmptyIllustration />} styles={{ image: { height: 160 } }} />
    )}
  >
  ```

  **文案属页面语义**（含对象名与内联动作），由各页在自己的 `Empty` / `Table.locale.emptyText` 处传 `description` 覆盖。尺寸一律走 `styles.image`。
- **不写进 `@ant-design/icons`**：icon 体系的三条硬假设与本插画全部冲突——单色跟随 `currentColor`、尺寸 1em 随字号、语义是可复用符号。插画作为自研组件放 `components/illustrations/`。

### 6.1 元字段页

**采用通用表格页布局（§2.5）**。

**PageHeader 槽位**：标题区 =「元字段」；页面动作槽 = 空（新建入口在表格面板工具条）。

**筛选面板**（§2.6，label 走控件 `prefix`）：三项——名称 / 字段键（输入，placeholder「请输入名称或字段键」）、数据类型（选择，「请选择数据类型」）、引用状态（选择，「请选择引用状态」：全部 / 已被引用 / 未引用）。三项占第 1 行前 3 列，按钮块 `[重置] [查询]` 占第 1 行第 4 列。

**表格面板**：

- 工具条：左「元字段列表」，右主按钮「新增元字段」。
- 列：名称 · 字段键（mono）· 数据类型（徽章）· **被引用（可点，打开引用清单模态）** · 更新时间 · 操作。
- **「被引用」单元格为可点单元格**（§2.5 链接态样式）：有引用时显示「3 个模型」并可点，**这是引用清单的唯一入口**；「未引用」为纯展示不可点。
- 操作列：**`[编辑] [删除]`**；删除走确认模态（§2.4），被引用时禁用 + Tooltip 说明原因。**整行可点**进入编辑抽屉。
- **不开排序、不开筛选**。
- 分页：按 §2.5 通则。

**编辑抽屉**（§2.4 浮层通则）：

- 宽 **560**，全高，左侧两角取浮层圆角档。
- 头：字段名 + 引用计数徽标——**纯展示不可点**。
- 主体（滚动）用 `Form` + `Form.Item`，字段序：**字段键 → 名称 → 数据类型 → 类型参数（enum 选项行 / list 子项类型 / number 精度与单位）→ 校验规则构建器 → 默认值 → 帮助文字**。
- **必填项**（带必填标记、校验不过禁止保存）：**字段键、名称、数据类型、精度、单位模式**；单位模式选「时间单位组」时，**具体单位**同为必填。默认值、帮助文字、校验规则为选填。
- 底：右对齐 `[取消] [保存]`。**抽屉内无删除按钮**——删除入口在表格操作列。
- **新建**走同一抽屉的空白态，标题「新增元字段」。

**控件级规格**：

- **精度与单位控件**（number 专属，[01 §2.7](01-领域模型与协议.md)）：精度 = 0–6 步进器（默认 0）；单位 = 三态选择「无 / 纯标注（文本框）/ 时间单位组（下拉选 分钟 / 小时 / 天 / 周）」。
- **字段键控件**：始终可编辑（mono 字体），保存时唯一性校验，无锁定态。
- **数据类型控件**：随时可改；已被引用时修改后弹影响提示（即引用清单模态，§4.4）。
- **校验规则构建器**：规则行列表——「添加规则」下拉只给该类型的合法规则，每行 = 规则名 + 参数控件 + 删除。
- **默认值控件**：按类型渲染，皆含「未设置」态（boolean 即三态控件）。
- **不做**：object / list(object) 内部结构编辑（在节点模型页子组装）；`inputComponent` 暴露（按类型默认控件）。
