> 文档状态：v0.1（2026-08-11 自《07-UI设计规范》拆出）——本文档管**结构与行为**：面板原语、外壳、交互范式、逐页 UI 设计。
> 依赖：[05-产品规格](05-产品规格.md)（页面有什么、能干什么）、[07-主题与设计系统](07-主题与设计系统.md)（一切数值与 token）。
> **分工判据：值归 07，结构与行为归 08。** 本文一律引用 07 的 token 名与档位名，**不复制数值**——需要知道「16 是多少」请查 07，本文只说「取 `space/inner`」。

## 1. 设计原则

- **仅浅色主题，不做明暗切换**（00 决策 19）；撞色语言全站统一：深色侧栏 × 浅色主区。
- 状态一律**文字 + 图标 + 颜色**三通道，色弱可用。
- 克制阴影、清晰 1px 边框；禁止蓝紫渐变、装饰性衬线字体、库存图片和营销页布局。
- 桌面优先：最优 1600+，参考宽度 1280；**最小宽度按页定义**，窄于该页下限时由**面板内部自行滚动**（横向亦然，如宽表格在表格面板内横滚），不做布局降级；移动端适配阶段三。
- **组件库优先**：能由 antd 主题 token 达成的一律走 token，不写自定义样式；偏离与自研组件必须登记（[07 §6](07-主题与设计系统.md) 偏离项清单 / 本文 §5.2 自研组件清单）。

## 2. 面板原语与组合规则（00 决策 36）

全站一切容器——侧边栏、主区、列表面板、编辑面板、执行页三栏、抽屉、模态——都是**同一原语的配置差异**，不存在「页面类型学」。

### 2.1 面板原语 Panel

- **高度撑满父容器**；纵向三段式：
  - **头部**：固定不滚，可省略；
  - **主体**：滚动区，**必有**；
  - **底部**：固定不滚，可省略。
- 头/底与主体之间以 1px `--border` 分隔线相隔，分隔线**横贯面板全宽**。
- 头、底高度不设全局定值，由内容物按 padding 规范撑开（外壳的侧栏头与右侧头部除外，见 §3）。
- **宽度模式**只有两种：固定值 或 flex 占满剩余。

### 2.2 皮肤三档

| 皮肤 | 规格 |
|---|---|
| `card` | 白底 `--surface` + 1px `--border` + 面板圆角档 + 面板级阴影 + 内 padding `space/inner` |
| `dark` | 侧栏色系（07 的 sidebar 三色） |
| `plain` | 无底色无边框的结构容器（如右侧主区） |

### 2.3 组合规则

- 横向组合**最多三栏**；相邻面板间距 `space/panel-gap`。
- 承载面板的容器 padding `space/inner`。
- 允许嵌套（面板主体内再放横向面板组合），实践深度 **≤ 2**。
- 纵向堆叠时：高度按内容的面板取 hug，主面板取 flex 撑满剩余，间距同 `space/panel-gap`。

### 2.4 浮层同构

抽屉与模态是面板原语的**浮层形态**：继承三段式与头/底固定规范，差异仅在圆角档、遮罩与定位。弹层四级分工（§4.4）只管**用途归属**，结构规范不再单写。

| 浮层 | 尺寸 | 定位 |
|---|---|---|
| 抽屉 Drawer | **一律全高**（贴视口右缘，自 y=0 至底，覆盖 Sidebar 与 PageHeader）；**宽度逐页自定义** | 右侧滑出 |
| 模态 Modal | **宽高均可逐页自定义**，但不得超出视口可用尺寸 | 见下方定位规则 |

**模态定位规则**：模态高度 **≤ 视口高度 50%** 时，距视口上边界 **20%**（高位置，视线焦点处）；**其余情况一律垂直居中**。

**圆角**：见 [07 §3.2](07-主题与设计系统.md)——悬浮浮层（模态 / 下拉面板 / 气泡）四角取浮层档；**抽屉仅左侧两角取浮层档，贴视口边一侧为直角**（贴边角做圆会在视口边缘露出缺口）。

**遮罩**：色值取 `--mask`；**范围与层级不另立规范**，按 antd 默认行为，逐页只声明尺寸。

### 2.5 实例对照

| 实例 | 头部 | 主体（滚动） | 底部 | 宽度 / 皮肤 |
|---|---|---|---|---|
| 侧边栏 | logo + 应用名 | 菜单 | 收起/展开按钮 | 固定 `size/sidebar-w`（收起 `size/sidebar-w-collapsed`）/ `dark` |
| 右侧主区 | 页面头部 | 页面内容 | 省略 | flex / `plain` |
| 列表页·筛选面板 | 省略 | 筛选表单 | 省略 | flex · 高 hug / `card` |
| 列表页·表格面板 | 计数 + 新建按钮 | 表格（内滚） | 省略 | flex · 高撑满 / `card` |
| 编辑抽屉 | 对象名 + 引用徽标 | 表单 | 动作条 | 全高浮层 · 宽逐页定 / `card` |
| 详情二级页 | 面包屑 + 引用徽标 | 分区内容 | 操作条 | flex · 撑满 / `card` |
| 画布页 | 页面头部 | 画布（不滚动，平移缩放；检查器为浮动 `card` 面板） | 省略 | flex / `plain` |

## 3. 控制台外壳（00 决策 37 / 39）

### 3.1 结构与区域命名

外壳只有**两种**：**控制台外壳**（六页共用，本节）与**执行页外壳**（独立标签，[05 §9](05-产品规格.md)）。404 / 加载失败等以控制台外壳的空 PageBody 表达，不另立外壳。

> **执行页外壳继承本规范全部通则**——面板原语（§2）、色板与文字层级（07）、浮层规则（§2.4）、「页面级不滚、只在面板主体内滚」（本节）、区域命名术语（下表）。它不是另一套设计语言，只是**槽位内容与栏位比例不同**。差异部分（顶栏槽位构成、三栏宽度与皮肤、节点列表形态）与页面内容强耦合——执行页左侧深色栏装的是本实例节点列表，属**内容**而非导航，与控制台的 `Sidebar` 性质不同——故随该页评审时定义（§6），此处不预设。

```
┌───────────────────────────────────────────────────────────┐ Shell
│ ┌───────────┬───────────────────────────────────────────┐ │
│ │ Sidebar   │ PageHeader            高 60 固定           │ │
│ │ 240 ⇄ 64  ├───────────────────────────────────────────┤ │
│ │ 全高       │ PageBody              padding 16          │ │
│ │           │   面板组合置于其中，各自内滚                │ │
│ │ Header 60 │                                           │ │
│ │ Body 菜单 │              ← 内容区，逐页定义             │ │
│ │ Footer 56 │                                           │ │
│ └───────────┴───────────────────────────────────────────┘ │
│   Overlays  抽屉 / 模态 / Toast（§2.4）                    │
└───────────────────────────────────────────────────────────┘
```

**区域命名为规范术语**，逐页规范一律使用下表词汇，不得另造说法（「左边那栏」「上面那条」之类）：

| 术语 | 指代 |
|---|---|
| `Shell` | 整个外壳（含以下全部） |
| `Sidebar` / `Sidebar.Header` / `Sidebar.Body` / `Sidebar.Footer` | 左侧栏及其三段 |
| `MainColumn` | 右列（PageHeader + PageBody） |
| `PageHeader` | 右列顶部固定条 |
| `PageBody` | 右列内容区 —— **逐页定义的就是这里** |
| `Overlays` | 抽屉 / 模态 / Toast 层 |

- 左右两栏：`Sidebar` **固定宽全高**，`MainColumn` flex 占剩余。
- **页面级永不滚动**，一切滚动（纵向与横向）发生在面板主体内。
- 代码实现：`Sidebar` 用 antd `Layout.Sider`（`collapsedWidth` 正好承载展开 ⇄ 收起），菜单用 `Menu theme="dark"`；激活态左缘 3px 为登记偏离（[07 §6](07-主题与设计系统.md)）。

### 3.2 侧边栏（`dark` 面板）

| 段 | 规格 |
|---|---|
| 头部 | 高 `size/header-h`（与右侧头部同高，共享同一水平线）；logo 方块 + 应用名「FlowCanvas」；padding `space/inner` |
| 主体 | 六项菜单（图标 + 文字），内滚；激活态 `--sidebar-active` |
| 底部 | 高 `size/sidebar-footer-h`；仅放收起/展开按钮 |
| 右缘 | border-right 1px `--border` + 骨架级阴影 |

### 3.3 收起态（收起能力自阶段三提前入 MVP，修订 00 决策 17）

- 宽度 `size/sidebar-w` ⇄ `size/sidebar-w-collapsed`，切换带 150ms 宽度过渡。
- 收起后：菜单仅留图标居中，hover 出 tooltip 显示名称；头部仅留 logo 居中，应用名隐去；底部按钮变为居中图标。
- 激活态左缘 3px `--primary` 两态都保留。
- **菜单图标**：六项各配一枚 `@ant-design/icons` 图标（收起态唯一辨识依据，展开态也显示）；具体图标名起骨架时选定并回填。
- 状态存 `appSettings` 跨会话记忆；**仅手动触发**，不做窄屏自动收起。

### 3.4 右侧头部与槽位规则

| 项 | 值 |
|---|---|
| 高度 | `size/header-h` 固定，白底 `--surface` |
| 内 padding | 左右 `space/inner` |
| 下缘 | border-bottom 1px `--border` + 骨架级阴影 |

槽位自左至右：

```
[页面标题区] ·············· [页面动作槽] │ [同步徽标] [⋯]
                                       ↑ 1px 分隔，高 20
```

- **页面标题区**、**页面动作槽**：内容逐页定义（§6）。页面动作槽**可空**——新建入口下沉表格面板头部、保存下沉面板底部操作条（00 决策 38），多数配置页此槽为空。
- **工作空间簇**永远钉在最右角，跨页位置恒定：同步状态徽标（[05 §9.6](05-产品规格.md) 九态映射）+ `⋯` 更多菜单（导出 `.flowpack` / 导入 `.flowpack`；后续工作空间级操作也归此菜单）。

## 4. 全局交互范式

### 4.1 保存模型（混合）

- **表单类显式保存**（元字段、节点模型、驱动绑定）：编辑产生脏标记，点保存落库；「必需槽位未解析禁止保存」由保存按钮禁用逻辑承载。
- **流程画布即时自动保存**：增删节点、连线、拖动位置即时写入草稿——草稿允许不完整，发布门全量校验兜底。
- 关闭带脏标记的表单页给未保存确认。

### 4.2 撤销/重做

画布结构操作支持 `Ctrl+Z / Ctrl+Y`（会话级内存栈，不持久化）；表单类不做 undo（显式保存天然可弃改）。

### 4.3 校验反馈三级

1. **字段级**：失焦即时标红（必填、正则、类型）。
2. **对象级**：点保存时汇总（驱动槽位完整性等）。
3. **流程级**：发布时全局校验面板（六层全跑）。

画布上节点校验问题实时显示角标（如缺驱动输入）。

### 4.4 弹层四级分工

| 载体 | 用途 |
|---|---|
| 整页 | 控制台六页、执行页 |
| 抽屉（右侧滑出） | 轻对象编辑表单、只读快照查看、节点详情速览、引用清单 / 影响提示 |
| 模态 | 发布校验与确认、冲突三选一、破坏性确认（删节点、删实例、断开云、导入替换工作空间）、新建实例 |
| Toast | 保存成功、同步完成等瞬时反馈，**不承载错误详情** |

判据：需要对照上下文看的用抽屉，需要打断决策的用模态。结构规范见 §2.4。

## 5. 组件约束

### 5.1 已拍板的控件约束

- boolean 运行字段用**三态控件**（未设置 / 是 / 否）；空输入保存 = 显式清空（[01 §2.5](01-领域模型与协议.md)）。
- 受阻补值表单**预填快照默认值**作建议（仅建议，保存才落日志）。
- `link` 仅 `https / http / mailto` 渲染为可点击链接，其余纯文本；helpText / description 一律纯文本（[01 §2.6](01-领域模型与协议.md)）。
- 完成度显示格式「完成 3/5 · 跳过 2」，分母不含跳过（[02 §8](02-状态引擎规范.md)）。
- 导入 = 替换工作空间的破坏性确认模态，含「已自动备份」提示（[04 §3](04-存储与同步规范.md)）。
- **状态徽章**：底 = tint（色阶第 1 阶）、**文字 = Active（第 7 阶）**、图标 = 基色（第 6 阶）——文字取深阶是无障碍要求，见 [07 §2.5](07-主题与设计系统.md)。

### 5.2 自研组件清单

antd 覆盖不了、需自研的组件：条件树构建器、boolean 三态控件、画布节点卡与连线、驱动槽位绑定行。规格随对应页面设计沉淀。

### 6.1 元字段页（⚠ 面板组合待重写）

> **2026-08-11**：配置页范式改为「筛选面板 + 表格面板 + 编辑抽屉」（00 决策 38），原「列表面板 + 编辑面板」的 master-detail 组合**作废**，Figma `48:2` 待返工。下列**控件级**规格仍然有效，`PageBody` 面板组合与表格 / 筛选 / 抽屉规格待评审后补齐。

- **编辑区字段序**：字段键 → 名称 → 数据类型 → 类型参数（enum 选项行 / list 子项类型 / number 精度与单位）→ 校验规则构建器 → 默认值 → 帮助文字。
- **精度与单位控件**（number 专属，[01 §2.7](01-领域模型与协议.md)）：精度 = 0–6 步进器（默认 0）；单位 = 三态选择「无 / 纯标注（文本框）/ 时间单位组（下拉选 分钟/小时/天/周）」。
- **字段键控件**：始终可编辑（mono 字体），保存时唯一性校验；改键不断引用（关联走生成 ID，00 决策 31），无锁定态。
- **数据类型控件**：随时可改；已被引用时修改后弹影响提示（复用引用清单）。
- **校验规则构建器**：规则行列表——「添加规则」下拉只给该类型的合法规则，每行 = 规则名 + 参数控件 + 删除。
- **默认值控件**：按类型渲染，皆含「未设置」态（boolean 即三态控件）。
- **不做**：object / list(object) 内部结构编辑（在节点模型页子组装，00 决策 29）；`inputComponent` 暴露（MVP 按类型默认控件）。
- 待补：面板组合、筛选项与表格列、抽屉规格、空态设计、列表项信息密度。
