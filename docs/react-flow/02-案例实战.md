## 案例 1：可新增节点的受控画布

目标：掌握节点、连线、受控 change 和工具栏。

```tsx
import { useCallback, useRef } from 'react';
import {
  addEdge,
  Background,
  BackgroundVariant,
  Controls,
  MiniMap,
  Panel,
  ReactFlow,
  useEdgesState,
  useNodesState,
  type Connection,
  type Edge,
  type Node,
} from '@xyflow/react';

type StepData = {
  label: string;
};

type StepNode = Node<StepData>;
type StepEdge = Edge;

const initialNodes: StepNode[] = [
  {
    id: 'start',
    position: { x: 0, y: 80 },
    data: { label: '开始' },
  },
  {
    id: 'review',
    position: { x: 260, y: 80 },
    data: { label: '评审' },
  },
];

const initialEdges: StepEdge[] = [
  {
    id: 'start-review',
    source: 'start',
    target: 'review',
    type: 'smoothstep',
  },
];

export function EditableFlow() {
  const nextId = useRef(1);
  const [nodes, setNodes, onNodesChange] = useNodesState(initialNodes);
  const [edges, setEdges, onEdgesChange] = useEdgesState(initialEdges);

  const onConnect = useCallback(
    (connection: Connection) => {
      setEdges((currentEdges) =>
        addEdge({ ...connection, type: 'smoothstep' }, currentEdges),
      );
    },
    [setEdges],
  );

  const addNode = useCallback(() => {
    const sequence = nextId.current++;

    setNodes((currentNodes) => [
      ...currentNodes,
      {
        id: `step-${sequence}`,
        position: { x: 120 + sequence * 40, y: 180 + sequence * 30 },
        data: { label: `新节点 ${sequence}` },
      },
    ]);
  }, [setNodes]);

  return (
    <div style={{ width: '100%', height: 640 }}>
      <ReactFlow<StepNode, StepEdge>
        nodes={nodes}
        edges={edges}
        onNodesChange={onNodesChange}
        onEdgesChange={onEdgesChange}
        onConnect={onConnect}
        defaultEdgeOptions={{ type: 'smoothstep' }}
        fitView
      >
        <Background variant={BackgroundVariant.Dots} gap={20} />
        <MiniMap />
        <Controls />
        <Panel position="top-right">
          <button type="button" onClick={addNode}>
            新增节点
          </button>
        </Panel>
      </ReactFlow>
    </div>
  );
}
```

观察重点：

- 节点拖动后的 `position` 是由 `onNodesChange` 写回状态的；
- `addEdge` 会补充连线，并阻止相同端口之间的重复连线；
- `Panel` 固定在视口上，不随画布缩放。

## 案例 2：带状态和操作按钮的自定义节点

目标：掌握 TypeScript 节点联合类型、自定义 Handle、节点内部操作和性能边界。

### 2.2 自定义节点组件

```tsx
import { memo, useCallback } from 'react';
import {
  Handle,
  Position,
  useReactFlow,
  type NodeProps,
} from '@xyflow/react';
import type { TaskNode } from './flow-types';

const statusText = {
  pending: '待处理',
  running: '进行中',
  done: '已完成',
} as const;

export const TaskNodeView = memo(function TaskNodeView({
  id,
  data,
  selected,
}: NodeProps<TaskNode>) {
  const { updateNodeData } = useReactFlow();

  const markDone = useCallback(() => {
    updateNodeData(id, { status: 'done' });
  }, [id, updateNodeData]);

  return (
    <article
      className={`task-node task-node--${data.status}${
        selected ? ' is-selected' : ''
      }`}
    >
      <Handle id="previous" type="target" position={Position.Left} />

      <header className="task-node__header">
        <strong>{data.label}</strong>
        <span>{statusText[data.status]}</span>
      </header>

      {data.description ? <p>{data.description}</p> : null}

      <button
        type="button"
        className="nodrag nowheel"
        disabled={data.status === 'done'}
        onClick={markDone}
      >
        标记完成
      </button>

      <Handle id="next" type="source" position={Position.Right} />
    </article>
  );
});
```

### 2.3 注册和渲染

```tsx
import { memo } from 'react';
import {
  Handle,
  Position,
  ReactFlow,
  type Edge,
  type NodeProps,
} from '@xyflow/react';
import { TaskNodeView } from './TaskNodeView';
import type { AppNode, MilestoneNode } from './flow-types';

type Props = {
  nodes: AppNode[];
  edges: Edge[];
};

const MilestoneNodeView = memo(function MilestoneNodeView({
  data,
}: NodeProps<MilestoneNode>) {
  return (
    <div className="milestone-node">
      <Handle type="target" position={Position.Top} />
      {data.label}
      <Handle type="source" position={Position.Bottom} />
    </div>
  );
});

const nodeTypes = {
  task: TaskNodeView,
  milestone: MilestoneNodeView,
};

export function WorkflowCanvas({ nodes, edges }: Props) {
  return (
    <ReactFlow<AppNode>
      nodes={nodes}
      edges={edges}
      nodeTypes={nodeTypes}
      fitView
    />
  );
}
```

`nodeTypes` 放在组件外，避免每次渲染都产生新引用。按钮使用 `nodrag`，否则点击时可能同时触发节点拖动。

## 案例 3：禁止自环和循环依赖

目标：把业务规则放在 `isValidConnection`，避免“先加边再撤销”的闪烁。

新连线 `source -> target` 会形成环，当且仅当现有图中已经存在 `target -> ... -> source` 的路径。

```tsx
import { useCallback } from 'react';
import {
  getOutgoers,
  ReactFlow,
  type Edge,
  type IsValidConnection,
  type Node,
} from '@xyflow/react';

type AppNode = Node<{ label: string }>;
type AppEdge = Edge;

type Props = {
  nodes: AppNode[];
  edges: AppEdge[];
};

export function AcyclicFlow({ nodes, edges }: Props) {
  const isValidConnection = useCallback<IsValidConnection<AppEdge>>(
    (connection) => {
      const source = nodes.find((node) => node.id === connection.source);
      const target = nodes.find((node) => node.id === connection.target);

      if (!source || !target || source.id === target.id) {
        return false;
      }

      const canReachSource = (
        current: AppNode,
        visited: Set<string>,
      ): boolean => {
        if (current.id === source.id) {
          return true;
        }

        if (visited.has(current.id)) {
          return false;
        }

        visited.add(current.id);

        return getOutgoers(current, nodes, edges).some((nextNode) =>
          canReachSource(nextNode, visited),
        );
      };

      return !canReachSource(target, new Set());
    },
    [edges, nodes],
  );

  return (
    <ReactFlow<AppNode, AppEdge>
      nodes={nodes}
      edges={edges}
      isValidConnection={isValidConnection}
      fitView
    />
  );
}
```

生产项目通常还要返回失败原因。`isValidConnection` 只能返回布尔值，可以在 `onConnectStart` / `onConnectEnd` 配合本地状态或 Toast 显示“禁止自环”“会形成循环依赖”等原因。

## 案例 4：保存和恢复画布

目标：保存节点、连线、视口，并明确原型存储与领域存储的差异。

```tsx
import { useCallback } from 'react';
import {
  addEdge,
  Background,
  Controls,
  Panel,
  ReactFlow,
  ReactFlowProvider,
  useEdgesState,
  useNodesState,
  useReactFlow,
  type Connection,
  type Edge,
  type Node,
  type ReactFlowJsonObject,
} from '@xyflow/react';

type AppNode = Node<{ label: string }>;
type AppEdge = Edge;

const storageKey = 'react-flow-learning-demo';

const initialNodes: AppNode[] = [
  { id: 'a', position: { x: 0, y: 0 }, data: { label: '开始' } },
  { id: 'b', position: { x: 240, y: 0 }, data: { label: '结束' } },
];

const initialEdges: AppEdge[] = [
  { id: 'a-b', source: 'a', target: 'b' },
];

function isFlowSnapshot(
  value: unknown,
): value is ReactFlowJsonObject<AppNode, AppEdge> {
  if (!value || typeof value !== 'object') {
    return false;
  }

  const snapshot = value as Partial<ReactFlowJsonObject<AppNode, AppEdge>>;

  return (
    Array.isArray(snapshot.nodes) &&
    Array.isArray(snapshot.edges) &&
    Boolean(snapshot.viewport) &&
    typeof snapshot.viewport?.x === 'number' &&
    typeof snapshot.viewport?.y === 'number' &&
    typeof snapshot.viewport?.zoom === 'number'
  );
}

function SaveRestoreEditor() {
  const [nodes, setNodes, onNodesChange] = useNodesState(initialNodes);
  const [edges, setEdges, onEdgesChange] = useEdgesState(initialEdges);
  const { setViewport, toObject } = useReactFlow<AppNode, AppEdge>();

  const onConnect = useCallback(
    (connection: Connection) => {
      setEdges((currentEdges) => addEdge(connection, currentEdges));
    },
    [setEdges],
  );

  const save = useCallback(() => {
    localStorage.setItem(storageKey, JSON.stringify(toObject()));
  }, [toObject]);

  const restore = useCallback(() => {
    const raw = localStorage.getItem(storageKey);

    if (!raw) {
      return;
    }

    try {
      const snapshot: unknown = JSON.parse(raw);

      if (!isFlowSnapshot(snapshot)) {
        throw new Error('画布快照格式无效');
      }

      setNodes(snapshot.nodes);
      setEdges(snapshot.edges);
      void setViewport(snapshot.viewport, { duration: 200 });
    } catch (error) {
      console.error('恢复画布失败', error);
    }
  }, [setEdges, setNodes, setViewport]);

  return (
    <div style={{ width: '100%', height: 640 }}>
      <ReactFlow<AppNode, AppEdge>
        nodes={nodes}
        edges={edges}
        onNodesChange={onNodesChange}
        onEdgesChange={onEdgesChange}
        onConnect={onConnect}
        fitView
      >
        <Background />
        <Controls />
        <Panel position="top-right">
          <button type="button" onClick={save}>保存</button>
          <button type="button" onClick={restore}>恢复</button>
        </Panel>
      </ReactFlow>
    </div>
  );
}

export function SaveRestoreFlow() {
  return (
    <ReactFlowProvider>
      <SaveRestoreEditor />
    </ReactFlowProvider>
  );
}
```

真实业务中应继续补充：

- 用 zod 等协议层校验反序列化数据；
- 存储 `formatVersion`，升级时运行迁移；
- 捕获配额不足、JSON 损坏和版本不兼容；
- 把保存频率从高频拖动事件降到 `onNodeDragStop` 或防抖任务；
- 不把 `selected`、`dragging`、`measured` 等临时字段视为领域数据。

## 案例 5：FlowCanvas 领域模型适配

目标：避免让 React Flow 的 UI 数据结构侵入 `FlowDefinition` 和发布快照。

### 5.1 分开定义业务图与视图状态

```ts
import type { Edge, Node, Viewport } from '@xyflow/react';

type DomainNode = {
  id: string;
  title: string;
  schemaId: string;
};

type DomainRelation = {
  id: string;
  sourceNodeId: string;
  targetNodeId: string;
  kind: 'sequence' | 'optional' | 'reference';
};

type FlowDefinition = {
  id: string;
  nodes: DomainNode[];
  relations: DomainRelation[];
};

type FlowViewState = {
  nodePositions: Record<string, { x: number; y: number }>;
  viewport?: Viewport;
};

type CanvasNode = Node<
  {
    domainNodeId: string;
    title: string;
    schemaId: string;
  },
  'flowNode'
>;

type CanvasEdge = Edge<
  {
    relationId: string;
    kind: DomainRelation['kind'];
  },
  'smoothstep'
>;
```

### 5.2 领域模型转画布模型

```ts
export function toCanvasModel(
  definition: FlowDefinition,
  viewState: FlowViewState,
): { nodes: CanvasNode[]; edges: CanvasEdge[] } {
  const nodes: CanvasNode[] = definition.nodes.map((node, index) => ({
    id: node.id,
    type: 'flowNode',
    position: viewState.nodePositions[node.id] ?? {
      x: (index % 4) * 280,
      y: Math.floor(index / 4) * 180,
    },
    data: {
      domainNodeId: node.id,
      title: node.title,
      schemaId: node.schemaId,
    },
  }));

  const edges: CanvasEdge[] = definition.relations.map((relation) => ({
    id: relation.id,
    source: relation.sourceNodeId,
    target: relation.targetNodeId,
    type: 'smoothstep',
    data: {
      relationId: relation.id,
      kind: relation.kind,
    },
    animated: relation.kind === 'optional',
  }));

  return { nodes, edges };
}
```

### 5.3 拖动只写视图状态

```ts
import type { OnNodeDrag } from '@xyflow/react';

const onNodeDragStop: OnNodeDrag<CanvasNode> = (_, node) => {
  updateViewState((current) => ({
    ...current,
    nodePositions: {
      ...current.nodePositions,
      [node.id]: node.position,
    },
  }));
};
```

### 5.4 新建连线先转业务命令

```ts
import type { OnConnect } from '@xyflow/react';

const onConnect: OnConnect = (connection) => {
  if (!connection.source || !connection.target) {
    return;
  }

  dispatch({
    type: 'flowRelationCreated',
    payload: {
      sourceNodeId: connection.source,
      targetNodeId: connection.target,
      kind: 'sequence',
    },
  });
};
```

这条边界带来四个直接收益：

1. 发布快照不携带 `selected`、`dragging`、`measured` 等 UI 字段；
2. 同一份流程定义可以有画布、时间线、列表等不同 ViewRenderer；
3. React Flow 升级或替换时，领域协议不需要跟着迁移；
4. 业务校验、发布校验和运行时引擎都面向稳定的领域对象。

## 6. 从案例继续扩展

| 需求 | 下一步 |
|---|---|
| 拖侧栏条目生成节点 | `screenToFlowPosition` + HTML Drag and Drop / Pointer Events |
| 自动布局 | 节点测量完成后接 Dagre、ELK 或 D3 Hierarchy |
| 多端口 | 每个 `Handle` 提供稳定 `id`，连线保存 handle ID |
| 动态端口 | 更新 DOM 后调用 `useUpdateNodeInternals` |
| 连线按钮或菜单 | `BaseEdge` + `EdgeLabelRenderer` |
| 分组和子流程 | `parentId` + `extent: 'parent'` |
| 撤销重做 | 只记录有意义的编辑事务，不记录每一帧拖动 |
| 大图 | 精确 store selector、组件 memo、渐进渲染和实际性能测量 |
| 后端保存 | 领域 schema 校验 + 版本字段 + 乐观并发控制 |
